# 报告视觉设计系统（v7.1 · 大厂研报版式）

> **来源**：2026-08-18 美的集团七步财报分析报告实战沉淀（老板要求按"大厂审美"重做，Stripe/Apple/Tesla 混搭风）。
> **适用**：七步财报分析最终 HTML 报告的**版式与组件**规范。本文件是「可选增强层」——当模板默认样式（v6.4/6.5 深蓝金棕）被老板批评"太丑/太普通/没层次"时，按下述方案重构版式；AI 直接套用下方 CSS 与 HTML 骨架，不许自创组件。
> **原则**：只换色/只加几个变量 ≠ 视觉升级；**必须做版式重构**（卡片化 + 层级化 + 留白），否则没意义。

---

## 一、设计哲学（三个关键词）

1. **研报感**：像 Sequoia / McKinsey / 高盛研报——头部信息卡、KPI 网格、风险卡、数据表带渐变表头。
2. **信息层级**：一眼能扫出「结论 → 依据 → 数据」，数字是大字、说明是小字、注释是浅灰。
3. **克制配色**：主色只用 1 个（紫蓝），辅助色 2-3 个（金/绿/红），其余全灰阶。禁止彩虹色堆砌。

## 二、核心调色板

```css
:root {
    /* 主色：Stripe 紫蓝 */
    --brand:       #635bff;   /* 主品牌色：标题条、渐变起点 */
    --brand-dark:  #4f46e5;   /* 主色 hover/深变体 */
    --navy:        #0a1628;   /* 深海军蓝：正文标题、表格表头渐变 */
    --navy-2:      #152238;   /* 深蓝变体：卡片深色背景 */
    --navy-3:      #1a2744;   /* 深蓝变体：渐变终点 */
    --gold:        #c8943b;   /* 琥珀金：强调、渐变收尾 */
    --green:       #16a34a;   /* 绿：跌/负面变化（中国惯例：跌=绿） */
    --red:         #d63384;   /* 红粉：涨/正面变化（中国惯例：涨=红） */
    --gray-500:    #6b7280;   /* 次要文字 */
    --gray-400:    #94a3b8;   /* 辅助文字 */
    --gray-200:    #e2e8f0;   /* 分隔线 */
    --surface-1:   #ffffff;   /* 卡片底色 */
    --surface-2:   #f5f6fa;   /* 区块底色（卡片渐变起点） */
    --bg-gradient: linear-gradient(135deg,#f5f6fa 0%,#ebeef5 100%); /* 页面底 */
}
```

**涨跌色注意**：中国惯例 **涨=红 `--red`、跌=绿 `--green`**（与欧美相反），KPI 趋势、表格趋势列必须按此着色，配浅色底徽章：涨 `rgba(214,51,132,0.10)` + 红字、跌 `rgba(22,163,74,0.10)` + 绿字。

## 三、组件规范（直接可复制）

  <div class="meta-card-icon">📚</div>
  <div class="meta-card-body">
    <div class="meta-card-eyebrow">数据底座</div>

</div>
```

### 3.3 KPI 网格（6 卡 3×2，替代裸 KPI div）

**痛点**：KPI div 流式平铺无网格无强调。必须 `display:grid; grid-template-columns:repeat(3,1fr)`。

    <div class="kpi-icon">💰</div>
    <div class="kpi-label">营业收入 (2025)</div>
    <div class="kpi-value">4,564.52<span class="kpi-unit">亿</span></div>
    <div class="kpi-delta up">↑ 12.1% YoY</div>
  </div>
  <!-- …共 6 张 -->
</div>
```

### 3.4 风险卡网格（3 列彩色左边条，替代裸 ul/li）

  </div>
  <!-- risk-high=红边条 / risk-info=蓝边条 / risk-warn=黄边条 -->
</div>

**痛点**：默认细线表 + 左对齐全文本是第四显丑源。必须：表头深色渐变、数值列右对齐+等宽数字、最新年高亮、斑马纹、外层圆角阴影。

## 六、Do's & Don'ts

| Do | Don't |
|----|-------|
| 数据来源/口径说明压成一张 meta 卡 | 用两段裸 `<p>` 塞头部 |
| KPI 用 3 列网格 + 渐变顶条 | KPI div 流式平铺 |
| 风险/关注点用彩色左边条卡片 | 用裸 `<ul><li><strong>` |
| step 标题加数字水印 + 三层布局 | 普通蓝色 `<h2>` |
| 表格：深色渐变表头 + 数值右对齐 + 斑马纹 | 默认细线表 + 全左对齐 |
| 状态列用圆角徽章 | 裸 ✅ 文字 |
| 关键数字加金色背景带 | 所有文字同色平铺 |
| 涨红跌绿按中国惯例配浅底徽章 | 一律绿色/红色误导 |
| 整页加微弱 SVG 噪点纹理提升质感 | 纯白背景无质感 |

## 七、落地方式（两档）

- **轻档（已有 v6.4/6.5 模板时）**：把 §二 调色板变量 + §三 各组件 CSS 追加进模板 `</style>` 前，并把 HTML 结构按 §三 骨架替换（执行摘要 / step 标题 / 表格 class / 状态徽章 / insight 列表）。
- **重档（报告被反复批评太丑时）**：按本文件从零重排整页版式，参照 2026-08-18 美的报告（`/Volumes/KIOXIA/Win11Share/美的集团/美的集团_七步财报分析/美的集团_七步财报分析.html`）效果为准。

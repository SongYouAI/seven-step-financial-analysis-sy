# 反面假设清单（内容五件套 ④ 四链 · 按九步组织）

> 用途：每个判断必须至少附 1 条「也可能是……」（触发条件），对应质检 R7。本清单为各步提供反面视角弹药，避免单一解读（缺陷 C3/C5）。
> 维护：按步骤分组，每步 ≥3 条。

## 第1步 营收与盈利质量
1. 扣非/归母高，也可能是当年一次性资产处置拉高归母，主业实则走弱。
2. OCF/归母高，也可能是拖欠供应商货款（应付暴增）撑出来的，非真盈利。
3. 自由现金流为正，也可能是削减CAPEX 苟出来的，长期竞争力在流失。
4. CAGR 高，也可能是基数极低或并表虚高，非内生增长。

## 第2步 成本费用
1. 毛利率高，也可能是行业周期供需错配（缺货涨价），非持久壁垒。
2. 费用率下降，也可能是费用资本化处理，利润被粉饰。
3. 财务费用为负（存款息多），也可能是囤积现金不投产，管理层保守。
4. 研发费用率高，也可能是撒网式低效投入，无产出转化。

## 第3步 增长
1. 历史CAGR 高，也可能已过高点，未来增速必然回落（均值回归）。
2. 一致预期高，也可能是券商乐观共识，落地概率低（预期>>历史需警惕）。
3. 成长期定位，也可能是靠烧钱换份额，终难盈利。
4. 量增驱动增长，也可能是降价促销走量，利润反被侵蚀。

## 第4步 业务构成
1. 收入占比高≠利润贡献高，可能是赔本赚吆喝的低毛利业务。
2. 单一业务占比高，也可能是该业务正处于爆发期，集中度暂可接受。
3. 第二曲线占比升，也可能是并购并表而非有机增长，协同难证。
4. 毛利率对比优，也可能是不同会计口径（如研发费用化 vs 资本化）造成虚假优势。

## 第5步 资产负债
1. 资产负债率低，也可能是隐藏表外负债或租赁负债未计。
2. 有息负债少，也可能是依赖拖欠供应商（无息但脆弱）撑运营。
3. 净经营资产收益率高，也可能是激进少计提折旧，资产虚低。
4. 商誉占比高，也可能是溢价收购吹大，未来减值炸雷。

## 第6步 投入产出
1. WC 为负（占款），也可能是对上游极度强势但行业地位在松动。
2. 人均收入高，也可能是外包生产，真实人效被低估。
3. 收入增速>人数增速（规模效应），也可能是裁员降本，非效率提升。
4. 固定资产轻，也可能是过度外包，供应链掌控力弱。

## 第7步 收益率（杜邦）
1. ROE 高，也可能是高杠杆撑的，下行周期放大亏损（非真本事）。
2. ROIC>WACC，也可能是 WACC 取值偏低（无推导），虚高结论。
3. 周转率下降，也可能是主动扩产在建工程未转固，未来回升。
4. 净利率高，也可能是一次性投资收益计入，不可持续。

## 第8步 八问
1. 护城河判断，也可能是短期红利（政策/缺货），同行扩产后消失。
2. 管理层「能力强」，也可能是周期顺风使然，逆风才见真章。
3. 空间大，也可能是市场测算过于乐观，天花板被高估。
4. 风险低，也可能是未在报表体现（如未决诉讼/关联交易）。

## 第9步 同行对比
1. 毛利率优于同行，也可能是会计口径不同（研发资本化等），需先对齐。
2. 费用率低，也可能是研发投入不足，牺牲长期竞争力换短期美观。
3. ROE 高，也可能是杠杆更高，风险调整后未必更优。
4. 人员效率高，也可能是外包/劳务外包，口径不可比。

> **使用纪律**：报告每步至少引 1 条本清单（或自写）反面假设，并写明「触发条件」。禁止只给单一乐观/悲观结论。

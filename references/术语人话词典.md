# 术语人话词典（内容五件套 M1 · 普通投资者版）

> 用途：报告中词典内术语**首次出现**必须配 ≤25 字大白话 + 一个生活类比（对应质检 R3）。本词典即「术语裸奔」扫描的基准清单。
> 维护：新增术语保持「术语 / 大白话 / 生活类比」三列。

| 术语 | 大白话（≤25字） | 生活类比 |
|------|----------------|---------|
| 归母净利润 | 属于公司股东、能落袋的净利润 | 全家算完账真能存下的钱 |
| 扣非净利润 | 剔掉卖房卖地补贴后的主业利润 | 工资外的兼职+中奖不算真本事 |
| 非经常性损益 | 一次性外快，明年未必有 | 中奖彩票，不能当月工资 |
| 经营净现金流 | 主业实打实收到的现金 | 开店每天收到的真钞票 |
| 自由现金流 | 扩产后还能分给股东的真金 | 供完房车后还能旅游的钱 |
| OCF/归母净利润 | 赚的利润里现金占几成 | 工资里实发到手的比例 |
| 毛利率 | 卖价减成本剩多少比例 | 包子皮馅之外的毛利空间 |
| 净利率 | 扣完所有费用落袋的比例 | 交完房租水电剩的钱 |
| 研发费用率 | 营收中拿来搞研发的比例 | 收入里投去学习进修的部分 |
| 销售费用率 | 营收中砸钱卖货的比例 | 用来打广告跑业务的开销 |
| 资本开支(CAPEX) | 买厂房设备的钱 | 买房置产的大笔支出 |
| 营运资本(WC) | 日常占用的流动资金 | 进货垫的周转金 |
| 资产负债率 | 资产里借来的钱占几成 | 房子首付外的贷款比例 |
| 权益乘数 | 1元股东钱撬动几元资产 | 首付越少杠杆越大 |
| ROE | 股东每投1元一年赚多少 | 本金的年回报率 |
| ROA | 总资产每1元赚多少 | 全部家底的平均收益率 |
| ROIC | 投进生意的钱赚多少 | 实打实做生意的回报率 |
| 杜邦分析 | 把ROE拆成利润×周转×杠杆 | 拆开看成绩好在哪科 |
| 总资产周转率 | 1元资产一年做多少营收 | 店面每平米的产出 |
| 净利−毛利差值 | 费用+税吃掉的利差 | 毛利润里的各种开销 |
| 商誉 | 溢价收购多付的部分 | 为招牌多付的溢价 |
| 在建工程 | 还没建好不能用的资产 | 在建没交房的期房 |
| 存货周转天数 | 货平均压多少天卖出 | 库存清仓所需天数 |
| 应收周转天数 | 欠款平均多少天收回 | 客户拖账的天数 |
| 市占率 | 在行业里分到几成蛋糕 | 班里你的名次占比 |
| 护城河 | 长期比同行多赚的壁垒 | 独家秘方能挡竞争对手 |
| 戴维斯双杀 | 业绩估值一起跌 | 工资降还被裁员双重打击 |
| CAGR | 多年平均年增速（平滑） | 几年下来的平均涨薪率 |
| 一致预期 | 券商预测的公司未来增速 | 大家猜你明年能涨多少 |
| 净经营资产收益率 | 经营资产每1元赚多少 | 主业家底的回报率 |
| 1元收入WC | 做1元营收要垫多少周转金 | 每赚1元要先垫的本钱 |
| 人均收入 | 每个员工平均创收多少 | 人均产值 |
| 第二曲线 | 主业之外的新增长引擎 | 副业成了新饭碗 |
| 研发投入资本化 | 把研发费用算成资产不计入花费 | 把学费算成资产不算开销 |
| WACC | 公司加权平均的资金成本 | 借钱的加权平均利息 |
| 合理价值 | 按未来盈利算出的公道价 | 东西值多少钱的估值 |
| 安全边际 | 现价低于合理价值的空间 | 打折买的缓冲垫 |
| 动态估值倍数 | 按未来盈利给的市盈率 | 按明年收入估的身价 |
| 经营活动利润 | 主业赚的，不含投资理财 | 工资收入不含理财收益 |
| 金融利润 | 投资理财等副业收益 | 理财和投资收益 |

# 七步财报分析法（Seven-Step Financial Analysis）

> **升级版财报分析引擎**：基于饶刚《简明财务分析》"七步法"，专为二级市场普通投资者设计。内置指标生成引擎（8 个 Python 脚本，零外部依赖），把任意来源的财务数据标准化后，自动完成七步分析 + 商业模式八问 + 同行对比，产出**笔记风格 + 大厂研报版式**的 HTML / Markdown 双份报告。
>
> 数据来源支持**三种方式**：本地 CSV / 联网 MCP 在线拉数 / 手动输入——没有 CSV 也能闭环产出报告。

## ✨ 功能特性

- **Phase 0 指标生成引擎**：内置 `scripts/` 8 个 Python 脚本，把任意来源（CSV / MCP在线 / WebSearch / 手动输入）的三张原始表组装为标准化 `output.csv` + 辅助 CSV，七步分析统一读引擎产物，**单入口闭环、杜绝口径不一致**
- **九大环节全覆盖**：七步（营收→成本→增长→业务构成→资产负债→投入产出→收益率）+ 商业模式八问 + 同行对比
- **数据可信度分级 🥇🥈🥉🚫**：原版官方 / 结构化精选 / 外部旁证 / 非公司确认，全报告统一符号，每个数字可追溯
- **异常点零幻觉闭环铁律**：每个异常点终态只能是 `✅已验证（引年报原文）/ ✅已解释（引旁证）/ ⚠️数据缺口（方向+来源档位）`，**严禁"未验证/无法验证"悬空表述**
- **资料丰度四档自适应**：RICH（有PDF年报）/ MEDIUM / LEAN / ONLINE 客观决策树，按档位自动调整验证深度，不强行追问
- **内容五件套质检**：一问二算三标四链五用——每个判断必带可复算算式 + 阈值标尺 + 因果链 + 反面假设 + 投资含义，数字自相矛盾无处藏身
- **16 张交互图表**：Chart.js 本地化（随报告拷贝 assets/ 即可离线渲染），图表数据由 `build_report_data.py` 自动生成，根除手填错误
- **大厂研报版式**：Stripe 紫蓝 + 深海军蓝 + 琥珀金三色体系，执行摘要卡片化、KPI 网格、风险卡、数据表渐变表头、step 数字水印，涨红跌绿按中国惯例

## 📖 七步详解（每步看什么 / 为什么）

> 每步行文统一「笔记风格」：**动词式标题** + 目的（一句话说清这步看什么）→ 数据/分析（做什么+为什么看+怎么看）→ 告诉普通投资者（≤3 条大白话结论）。判断必给可复算算式，必附「也可能是…」反面假设，必与前后步骤互相印证。

### 第1步 · 看营收数据（意义：建立基本面轮廓，评估盈利质量）

- **规模与成长**：营收/净利绝对规模、成长轨迹、CAGR（算一算：`营收 CAGR = (B÷A)^(1/年数)−1`）
- **盈利质量四关系**（本步核心）：
  1. **扣非/归母**（主业纯度）：`>0.9 优 / 0.8~0.9 良 / <0.6 警戒`——比值常年 >0.9 主业扎实，明显 <0.8 警惕利润掺"外快"（政府补助/卖资产）
  2. **经营利润 vs 金融利润**（利润来源）：`>0.8 主业主导 / <0.5 偏投资平台`——金融利润占比过高像"投资平台"（例：泰格医药过半利润来自公允价值变动）
  3. **OCF/归母**（现金含量）：`>1.2 优 / 0.8~1.2 良 / 连续2年<0.6 预警`——利润是账面数，现金才是真钱
  4. **自由现金流**（真实盈利）：`OCF − CAPEX`——持续为正=能自给自足；持续为负=靠融资续命
- **未来展望**：历史 CAGR vs 券商一致预期——预期远高于历史 = 市场在讲"增长故事"，警惕兑现不了（例：卓胜微预期从三位数回落到 12%，PE 市值大缩水）
- **小白翻译**：这一步像体检先量身高体重血压，虽不能确诊，但能快速圈出重点方向。

### 第2步 · 看成本费用构成（意义：理解盈利结构，识别效率变化）

- **毛利率**：`(营收−营业成本)÷营收`，近 3 年波动 `<3pct 优 / 3~5pct 良 / >5pct 警戒`（价格战/优势削弱信号；例：科沃斯 28.59%→51.41%，代工转自主品牌）
- **毛利率−净利率差值**：期间费用+减值的总侵蚀，突然扩大=费用/减值异动
- **四项费用率拆解**：
  - 研发费用率（技术/产品驱动型关键指标；查「开发支出」科目防**研发资本化粉饰利润**）
  - 销售费用率（持续高企=靠砸钱换增长；科沃斯 24.74% vs 石头 7.55% 两种打法）
  - 管理费用率（收入增速 vs 费用增速：收入跑赢费用=规模效应显现）
  - 财务费用率（`= 利息收入−利息支出`；为负=存款息>贷款息，账上闲钱多）
- **小白翻译**：高毛利 = 有护城河，但要防"虚高"；费用率赛跑看规模效应；研发资本化是利润粉饰警戒线。

### 第3步 · 看增长（意义：把握核心趋势，评估未来潜力）

- **增长率趋势**：逐年增速是"心电图"，异常负增长或骤升骤降都是深挖信号（科沃斯 2019 净利 −75% → 2020 暴增 430%，背后是退出低端代工）
- **CAGR 对比**：历史 vs 券商预期——预期>>历史 = 戴维斯双杀预警（业绩估值一起跌）
- **生命周期定位**：彼得·林奇五类（缓慢/稳定/快速/周期/困境反转）；周期型/困境反转型增速参考价值低，重点看拐点
- **增长质量**：量增/价增/并表增——**量增最实**，并表增不可持续
- **小白翻译**：戴维斯双杀 = 业绩估值一起跌，高增长股最怕预期减速；增长质量比速度重要。

### 第4步 · 看业务构成（意义：拆解收入引擎，定位驱动力来源）

- **收入结构**：各业务营收占比趋势（谁在扩张/收缩）；单一业务占比 `>70% 高集中风险`
- **毛利率对比**：利润贡献 vs 收入贡献对照——**营收大 ≠ 利润高**，低毛利业务可能"赔本赚吆喝"
- **核心利润引擎**：哪一业务贡献最多利润——是现金牛/增长引擎/拖油瓶
- **第二曲线**：能否扛住主业下滑？决定天花板
- **小白翻译**：看利润贡献，不是看收入贡献；单一依赖是风险；第二曲线决定天花板。这一步是财务数据与公司实际经营连接的桥梁——用分部数据验证管理层讲的战略故事是否属实。

### 第5步 · 看资产负债（意义：评估资产效率和财务风险）

- **资产结构**：流动 vs 非流动占比，重/轻资产判断（`1元收入固定资产` 轻<0.5 / 重>1.5）
- **负债安全**：`资产负债率 <50% 较安全 / >70% 要警惕`；有息债少、无息债多=占上下游便宜（科沃斯 2021 负债率 52.37% 但几乎全是无息负债）
- **营运资本 WC**：`WC = 应收+存货+预付 − 应付−预收−合同负债`；WC 为负或很小=占用上下游资金经营（格力、茅台）；WC 大=自己垫钱做生意
- **异常项目扫描**：商誉（`/净资产 >30% 减值风险`）、在建工程、存货增速 vs 收入增速（存货>>收入=滞销警戒）、**存贷双高**（货币资金高且借款高=资金占用异常）
- **小白翻译**：无息负债多=产业链地位强；WC 为负=占上下游款；商誉、存货暴涨是雷区。

### 第6步 · 看投入产出（意义：核心视角，理解商业模式本质）

- **三板斧**：营运资本（1元收入WC）+ 固定资产（1元收入固定资产）+ 人员（人均收入/人均利润/人均薪酬）——三样合起来就是商业模式画像
- **人员效率**：人均收入（石头 541 万 vs 科沃斯 167 万，因模式不同）；收入增速 vs 人数增速（收入>人数=规模效应）
- **商业模式分类**：轻/重资产、技术/制造/市场/资源驱动、资金输出/输入型
- **小白翻译**：WC 为负=占上下游款（格力茅台）；人均收入高=人效强；规模效应看收入是否跑赢人数。

### 第7步 · 看收益率（意义：综合评估股东回报和资产效率）

- **ROE 水平与趋势**：`>20% 优秀（巴菲特线） / 15~20% 良 / <10% 警戒`；ROA、ROIC 对照
- **杜邦三因素拆解**：`ROE = 净利率 × 总资产周转率 × 权益乘数`——三种赚钱模式：
  - **高利润模式**（净利率高：奢侈品、高端软件）
  - **高周转模式**（周转快：零售、快消）
  - **高杠杆模式**（借得多：银行、地产——风险最大，下行期放大亏损）
- **ROE vs ROA 差**：差越大=杠杆贡献越高，杠杆是双刃剑
- **ROIC vs WACC**：`ROIC > WACC = 真正在创造价值`（WACC 引用必须给推导，禁止空降）
- **周转天数**：应收/存货/固定资产周转——应收拉长=回款变差，存货增加=可能滞销
- **小白翻译**：ROE 高可能是真本事，也可能是借来的；高杠杆下行放大亏损；ROIC>WACC 才创造真价值。收益率是七步分析的"终点站"。

### 第8步 · 八问商业模式（意义：把财务数据讲成商业故事）

> 七步看的是"数据"，这一步看的是"生意"——把前面的数字串成完整商业故事。财务数据提供线索，非财务信息解释因果（**双循环验证**）。

| # | 问题 | 核心关注 | 周期企业优先级 |
|---|------|----------|----------------|
| 1 | 靠什么赚钱？ | 商业模式和核心驱动力 | 中 |
| 2 | 顺风还是逆风？ | 外部宏观环境、周期位置 | **高** |
| 3 | 空间有多大？ | 行业天花板和成长空间 | 中 |
| 4 | 竞争格局好不好？ | 行业集中度、竞争态势 | 高 |
| 5 | 护城河是什么？ | 品牌/技术/成本/网络效应 | 高 |
| 6 | 管理层行不行？ | 能力、诚信、战略眼光 | 高 |
| 7 | 风险在哪里？ | 经营/财务/行业/政策风险 | 高 |
| 8 | 未来会怎样？ | 短期/中期/长期预测 | 中 |

> **写作要求**：每问答案必须回指前七步具体数字作证据（禁止形容词空断言）+ 附"什么情况会推翻这个判断" + 给出跟踪指标。

### 第9步 · 同行对比（意义：横向对标，定位企业相对竞争力）

- 选择 3 家同行业/业务相似公司，**六维真数据对比表**（禁止"同行普遍…"糊弄）：

| 维度 | 指标 |
|------|------|
| 增长能力 | 营收/净利润增长率、CAGR |
| 盈利能力 | 毛利率、净利率 |
| 费用结构 | 销售费用率、研发费用率 |
| 资产效率 | 1元收入需WC、1元收入需固定资产 |
| 人员效率 | 人均收入、人均净利润、人均薪酬 |
| 收益率 | ROE、ROA、ROIC、杜邦三因素 |

- **估值含义（对接动态估值法 skill）**：推导链 `合理价值 = [FY3有效盈利 × 动态估值倍数 ÷ (1+贴现率)³] + 三年分红`，FY3 有效盈利 = 一致预期 × 0.9（默认打折，可设 `CONSENSUS_DISCOUNT=1.0` 关闭）；输出合理价值区间（**禁止无推导单点目标价**）+ X 值判定
- **术语隔离硬约束**：护城河（定性五类）在第8步、护城河系数（定量 1.25/1.0/0.8/0.6）在估值段，分节呈现禁止混用

### 异常点零幻觉闭环铁律

每个异常点终态三选一（必须写验证来源）：
1. `✅ 已验证（202X年报）：…原文…`
2. `✅ 已解释（招股书/CSV旁证）：…`
3. `⚠️ 数据缺口（方向：…，待补XX资料）` — 仅 LEAN 模式仍查不到的极个别情况

**硬禁**：任何步骤正文/异常点表/结论不得出现「未验证」「无法验证」「部分解释」「待年报验证」等悬空表述。

### 资料丰度四档（客观决策树，自动归入）

| 档位 | 客观判定 | 验证范式 |
|------|---------|---------|
| **RICH** | 有 ≥3 年 PDF年报 + 结构化CSV | 全量异常点✅闭环（引PDF原文） |
| **MEDIUM** | 有CSV + 部分公告，无完整PDF年报 | 异常点✅已解释（引CSV/招股书旁证） |
| **LEAN** | 仅CSV，无PDF年报 | 异常点✅已解释（引CSV/常识）；真无源→⚠️缺口 |
| **ONLINE** | 无本地文件，联网/MCP拉数 | 拉三表→Phase 0→转 MEDIUM/LEAN 处理 |

### 其他硬规则

- **期次隔离**：中报 H1 与年报 YOY 必须分列标注，不混算同比
- **状态精确度**：回购/分红/评级等"已公告未实施"必须标「待股东会审议/董事会通过待实施」，不得写成已落地
- **零幻觉**：每个数字必须可追溯到某档来源；irm 互动记录禁止作为公司确认事实

## 📐 内容五件套（每个判断性结论必达）

> 源于宁德时代 RICH 档报告实战教训：报告写过「扣非/归母=0.84」但表内复算 `645.08÷722.01=0.89`——数字自相矛盾无人察觉。根因是模板只要求结论、不要求推导。五件套强制每个判断带「算式+标尺+反证」。

| 件 | 名称 | 含义 | 失败标志 |
|----|------|------|---------|
| ① | **一问** | 大白话摆出这一步回答的问题 | 直接上结论，读者不知在判什么 |
| ② | **二算** | 可复算算式（含 `=` 与数字）+ 声明口径 | 只给「0.84」不给 `645.08÷722.01` |
| ③ | **三标** | 引用阈值标尺库「优/良/警戒」+ 出处 | 说「质量好」却无标尺 |
| ④ | **四链** | 因果链 ≥2 跳 + ≥1 条反面假设 | 只给单点结论，无推导无反证 |
| ⑤ | **五用** | 投资含义（对股东意味着什么、盯什么） | 分析完不落地到决策 |

**两条方法论护栏**：
- **G1 模糊的正确 > 精确的错误**：允许近似估算但必须标口径，不纠结二级精度
- **G2 口径声明强制**：每个比率首次出现必声明——平均 vs 期末、是否含资本化研发、经营/金融利润划分

**四个横向机制**：M1 术语人话卡（词典术语首现配大白话+类比）/ M2 阈值标尺库（判断就近引用）/ M3 步骤咬合区（每步结尾「与其他步骤的印证」）/ M4 双循环验证（数字→故事→数字回环）。

## 🖥️ 报告生成（模板占位符方案）

- 使用预定义 `report_template.html`，AI 只做 `{{占位符}}` 替换，**不修改 CSS/结构**
- 文件级占位符：公司名/代码/行业/日期/评级/KPI/警告框/档位徽章/评级配色
- 步骤级占位符：`{{STEP1_CONTENT}}` ~ `{{STEP9_CONTENT}}`（每步包 `<section id="stepN" class="step-card">`）
- 图表数据占位符：16 个（推荐先跑 `build_report_data.py` 自动生成）
- 年份动态化：`{{CHART_YEARS}}` 驱动全部图表 X 轴，支持任意区间
- 业务板块 N 段：`{{BUSINESS_SEGMENT_NAMES}}` + 数组占位符，多业务不截断
- **Chart.js 本地化**：拷贝 `assets/` 与 HTML 同级，断网/分享后仍可渲染，缺失自动回退 CDN
- 生成后验证：无 `{{` 残留、16 图渲染正常、档位徽章已填、KPI 涨跌类正确、打印预览、手机窄屏适配
